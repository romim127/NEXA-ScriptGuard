# Principios de desarrollo

- Diseñar la arquitectura completa e implementar por incrementos verificables.
- Mantener módulos independientes, contratos compartidos, seguridad por diseño y compatibilidad hacia atrás.
- Vincular requisitos, reglas, pruebas y criterios de aceptación. Registrar decisiones mediante ADR y cambios mediante Git.
- Verificar evidencia y resultados de CI con el SHA correspondiente. Las decisiones finales requieren revisión humana.
- Consolidar las funcionalidades terminadas mediante PR y seguimiento explícito de los bloqueos. Evitar ramas indefinidas para incrementos terminados.
