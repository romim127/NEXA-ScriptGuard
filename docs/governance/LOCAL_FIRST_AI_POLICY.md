# Política de IA local de NextGenAI Infinity

El análisis principal funciona localmente y sin conexión después de instalar dependencias reproducibles. Las APIs externas son opcionales. Para futuras funciones de IA se prefieren modelos locales pequeños, instalación automatizada, conocimiento y datasets propios con procedencia y permisos, privacidad y verificación humana. La IA asiste y la persona verifica y decide.

La transferencia de scripts, evidencias o secretos requiere consentimiento explícito. Cualquier integración futura debe aplicar la [política de datos](DATA_HANDLING.md). La [evaluación de Ollama](../Ollama-analysis.md) registra el antecedente técnico.
